# 💼 VaultofCodes Internship Showcase Website

This project was built as part of **Task-3** in my Web Development Internship with **VaultofCodes**.  
It’s a beautifully designed **multi-page internship showcase** featuring four interactive internship cards, smooth transitions, and a stunning front page.

## 🌐 Live Demo
🔗 **View Project:** [[https://vamshikrishan.github.io/task-3-internships/](https://vamshikrishan.github.io/internship_page/)]

## ✨ Overview

This project presents four different internship roles offered by VaultofCodes:
1. 🌐 **Web Development Internship**
2. 📱 **App Development Internship**
3. 🐍 **Python Programming Internship**
4. 🤖 **Artificial Intelligence Internship**

Each internship page contains:
- Duration, stipend, and mode of work  
- Key learnings and tools  
- “Apply Now”, “Next”, and “Back” buttons  
- Smooth animated page transitions  

---

## 🧭 Navigation Flow
- A **Front Page** welcomes users with an engaging design.  
- From there, users can **start exploring internships** sequentially.  
- Each internship page includes navigation buttons for **Back / Next** with smooth **fade transitions**.  
- The final page loops back to the home screen.
